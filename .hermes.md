# JarvisLab — Hermes project rules

When working in this repo or user asks for **voice / nói chuyện / gọi điện AI**:

1. Prefer MCP tools from server **jarvislab** (`mcp_jarvislab_voice_*`).
2. For continuous chat: `voice_wait_for_speech` → short reply → `voice_speak` → loop.
3. Spoken answers: 1–3 plain Vietnamese sentences, no markdown.
4. Stop on tạm biệt / bye / thôi.
5. Local entry: `python jarvis_call.py` or `npm run call`.
6. Tests (no human speech): `npm test`, `npm run test:e2e`, `node scripts/auto_full_test.js`.
7. Fix Hermes MCP env with `python scripts/fix_hermes_mcp.py` if tools fail to spawn Python deps.
